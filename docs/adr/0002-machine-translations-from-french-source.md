# Machine Translations generated from the French Post, never hand-edited

Posts are written in French; each English Translation is generated by an LLM and committed next to its Post. The French Post is the single source of truth: Translations are never hand-edited, and a Stale Translation is regenerated whole, overwriting any edits. Fixes go into the French Post or the translation prompt. Translation runs locally through Claude Code on the owner's subscription, from a lefthook `pre-commit` job that skips Drafts; CI fails a PR that still contains a Stale Translation.

## Considered Options

- Browser or Google translation: no indexable English pages, mangles code blocks.
- Run-time LLM translation: needs a server and pays per view, which a static site doesn't fit.
- Translation in CI through an LLM API or a free OpenRouter model: needs a paid key or depends on free-tier limits and model availability.
- Claude Code in GitHub Actions with a subscription token: documented, but subscriptions are meant for ordinary individual usage, so we kept it local.
- Merging hand edits on regeneration: more complex, and it puts two sources of truth in competition.
